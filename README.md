# J.K. Hospital Dental Care Center Website

A responsive single-page website starter for J.K. Hospital Dental Care Center, Prayagraj.

## Before publishing
Replace:
- clinic phone number
- WhatsApp number
- exact address
- clinic timings
- doctor profile/photo
- clinic logo
- Google Maps link

The appointment form is intentionally not connected to a number yet. This can be connected to WhatsApp, email, or the existing JKH Dental/Cloudflare system.

## Run
Open `index.html` in any modern browser.

## Suggested next phase
Connect the appointment form to the existing JKH Dental backend so website appointments can create/lookup patients and generate a UHID.
